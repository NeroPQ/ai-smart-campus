# Nucleus UI visual adaptation

Reference supplied by the site owner: [Nucleus UI LITE — Get Nucleus Plus](https://www.figma.com/design/JSUGwztPTpnJgm6WBOP006/?node-id=16391-2120).

The official Figma integration was used to read the reference. Website content and interactions are adapted to AI Smart Campus rather than reproducing the UI kit's sales page.

## Design sources

- Hero: node `16391:2803`; Inter Bold, 64 px / 1.2, text `#131214`, background `#efefef`.
- Primary action: node `16391:2812`; `#7257ff`, white label, 48 px height, pill radius.
- Supporting content: node `16391:2809`; Inter Regular, 18 px / 1.5.
- Numeric highlights: node `16391:2847`; purple 40 px bold numbers.
- Surface pattern: node `16391:2866`; `#f4f6f7`, `#daddde` border, 8 px corners.
- Decorative hero glow: node `16391:2804`, downloaded to `dist/assets/nucleus-hero-glow.png` from the asset URL returned by Figma. It is used as a decorative background, with no text content embedded in the image.

Product screenshots, Figma branding and purchase links in the reference are not part of this educational website's content.
